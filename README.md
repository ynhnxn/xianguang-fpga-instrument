# 弦光：具有三维表情控制的32声部FPGA电子乐器

基于高云FPGA的电子乐器项目，结合实体按键、压力片、旋钮、LED演奏指引和Android辅助App，实现可独立演奏、可展示多声部合成、可进行蓝牙参数控制与曲谱跟随练习的完整系统。

本仓库用于项目介绍和参赛软件代码包的阅读导航，**不公开工程源码、位流、ESP32固件或App安装包**。完整工程以通过赛事指定渠道提供的代码包为准；本仓库文档本身不能用于编译或烧录。

## 项目功能

| 功能 | 说明 |
|---|---|
| 三维表情控制 | 按键控制音符，压力片控制力度/音量，旋钮控制颤音深度 |
| 32声部合成 | FPGA内实现独立声部状态、音符分配、包络与混音，可重叠新音和释放尾音 |
| 音色与包络 | 支持两种波形音色、不同包络以及八度切换 |
| 回声效果器 | FPGA内部实时反馈延迟处理，支持不同效果档位 |
| 实体LED指引 | 支持按键灯光反馈和脱离手机的曲谱跟随练习 |
| 蓝牙与App | 支持设备连接、参数设置、曲谱管理/传输及状态查看 |
| 声部监视器 | App用32个格子显示FPGA回传的实际声部状态，区分保持、释放和空闲 |
| 自动演奏展示 | 板载键启动约18秒卡农主题短编曲，结合App展示多声部活动 |
| 内置练习曲谱 | 包含《小星星（一闪一闪亮晶晶）》等键号跟随曲谱 |

## 系统组成

```text
8路按键 ───────────────┐
压力片、旋钮 → ADC ────┤
                      ↓
                 高云FPGA ── I2S ── DAC ── 音箱/音频设备
                      │
                      ├── 8路LED演奏指引
                      │
                      └── UART ⇄ ESP32-C3 ⇄ BLE ⇄ Android App
```

| 部分 | 使用平台 | 承担的工作 |
|---|---|---|
| 实时音频与演奏逻辑 | Tang Mega138K B版，高云FPGA | 输入处理、声部合成、包络、混音、回声、教学与LED控制 |
| 模拟输入 | MCP3202双通道ADC | 采集压力片和旋钮信号 |
| 音频输出 | PCM5102A DAC | 将FPGA输出的I2S数字音频转换为模拟音频 |
| 无线桥接 | ESP32-C3 | BLE与UART之间的数据收发 |
| 辅助界面 | Android App | 参数控制、曲谱交互、设备状态与声部监视 |

音频逐样本处理由FPGA HDL实现。ESP32-C3和手机承担辅助交互与通信；正常实体演奏不依赖手机连接。

硬件采用B版/J13方案。自制外围板通过底面排母与J13连接；复现时应按代码包及实物资料中的接口定义操作，不能将外围板本地连接器编号直接当成开发板J13编号。

## 验证与结果说明

项目结合RTL行为仿真、高云综合/布局布线报告、实际演奏以及仪器测量进行验证。

- 团队实物测量记录中，按键至DAC模拟输出延迟约为**1.2ms**。这是所述测量条件下的结果，不代表所有输入、所有工况的最坏延迟。
- 团队已完成专用32频测试模式的模拟输出FFT验证。该测试与卡农音乐展示分别进行。
- 完整音乐RTL仿真达到32个同时活跃的声部，累计约1.037秒；仿真结果与实物FFT的证据类型不同。
- 既有高云报告中，内部50MHz时序检查的setup/hold违例均为0；外部接口完整时序签核不由这一结果替代。
- 代码包整理时，独立迁移副本通过FPGA回归、Java测试、App重新编译、ESP32重新编译和高云工程综合检查。

声部数指独立合成实例的活动数量，**不等于32个实体按键，也不等于音乐中始终存在32种不同频率**。App监视器展示声部状态，不是音频频谱仪；回声缓存也不计作新的合成声部。手机图形界面属于辅助显示，FPGA直接驱动的视觉反馈为实体LED。
